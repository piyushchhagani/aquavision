# AquaVision

## Multimodal Computer Vision System for Water-Surface Pollution Detection and Environmental Analytics

AquaVision is an extensible computer vision and data science platform designed to detect, classify, quantify, and analyze visible surface pollution in water bodies using images, video, and future satellite imagery.

---

## Project Status

🚧 **Version 0.1.0 — Initial Development**

---

## Problem Statement

Water bodies are increasingly affected by visible floating pollution such as plastic, bottles, containers, and other debris.

Manual monitoring is:

- Time-consuming
- Difficult to scale
- Subjective
- Expensive for continuous monitoring

AquaVision aims to provide an automated computer vision system that can detect and quantify visible surface pollution from visual data.

---

## Objectives

- Detect visible floating pollution
- Classify detected pollution objects
- Localize pollution using bounding boxes
- Segment pollution regions
- Estimate water-surface coverage
- Quantify pollution coverage
- Estimate pollution severity
- Analyze pollution in video
- Support future satellite and geospatial analysis
- Evaluate computer vision models using standard metrics
- Provide reproducible machine learning experiments
- Deploy an interactive analysis application
